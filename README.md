##APERTURE-X ##


Aperture X is an open source photo and video editor following popular applications like Adobe Lightroom and Photoshop, DaVinci resolve etc. Other than them however, Aperture X doesn´t rely on a pay per use or annual subscription model but is instead fully open sourced and user focused. Aperture X is equipped with lots of features, listed in the #Features# section down below.
